# UI Skills

A collection of deployed front-end showcase sites demonstrating animation,
interactivity, and modern UI craft — built with Next.js, Tailwind CSS, and
Framer Motion.

## Sites

| Site | Folder | Description | Live |
| --- | --- | --- | --- |
| The Bean | [`sites/the-bean`](./sites/the-bean) | High-end coffee brand site — steam, pouring, and rotating bean animations on a dark cinematic aesthetic | _pending deploy_ |

Each site in `sites/` is a fully self-contained Next.js app with its own
dependencies and Tailwind config, deployed as an independent Vercel project.
